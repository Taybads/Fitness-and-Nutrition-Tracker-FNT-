Project Description:
Fitness and Nutrition Tracker (FNT) is a Python application designed to help users track their workouts, meals, calories, and fitness information. The application allows users to manage their profiles, add and view health entries, import data from CSV and XML files, and visualize fitness and nutrition data. 

Key Features:
* User profile management
* Track workouts and meals
* Record calories, duration, quantity, and dates
* Import data from CSV and XML files
* View and manage health entries
* Visualize meal distribution
* Compare calories consumed and burned using charts 

Technologies:
* Python
* CSV & XML
* Matplotlib
* Python Lists & Dictionaries

Project Goal:
The main goal of the project is to provide an organized way for users to monitor their exercise, nutrition, and overall fitness metrics through data management and visualization.
